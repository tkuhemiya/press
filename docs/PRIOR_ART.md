# Prior art

Open this when an implementation gets stuck. Each row names a project we have opened, what it is, and the problems it covers, so the next attempt can start from that code.

Add a row when you study a project. Name the problems in words you would search for later. Keep a project we decided against. The note is what stops the same comparison from being run again.

## Diagram rendering

| Project | What it is | What it covers |
|---|---|---|
| [obsidianmd/pele](https://github.com/obsidianmd/pele) | Mermaid to SVG. Synchronous, no runtime dependencies, MIT. | Layered layout, edge crossings, compound groups, and reading order. Vendored in `src/layout/pele` and used for state machines. It beat elkjs on a side-by-side. Reading order stayed put, crossings dropped, curves got cleaner, and compound groups held together. The picture is [`docs/decisions/layout-pele-vs-elk.png`](decisions/layout-pele-vs-elk.png). Text is measured from a table of character widths, not from a DOM. A layered layout ranks the variables, so a cycle becomes a back edge. `causal-loop` uses its own force layout in `src/diagrams/causal-loop.ts`, and each named loop stays open. |
| [lukilabs/beautiful-mermaid](https://github.com/lukilabs/beautiful-mermaid) | Mermaid to SVG or ASCII, built on elkjs. | A theme built from two colours, and ASCII output. ASCII is the one to open when a diagram has to stay readable as plain text. |
| [kitlangton/merman](https://github.com/kitlangton/merman) | An experimental Mermaid renderer for the terminal. | Plain text, ANSI colour, and an OpenTUI widget, for flowcharts, sequences, and state diagrams. Open it with beautiful-mermaid when the target is a terminal. |
| [blushft/go-diagrams](https://github.com/blushft/go-diagrams) | Architecture diagrams from Go, a port of mingrammer/diagrams. | Node kinds for architecture pictures, including cloud icons. Press drew line glyphs in `src/diagrams/kinds.ts` so every kind shares one look with the rest of the page. A set of vendor logos would also need a licence check. |

## Print

| Project | What it is | What it covers |
|---|---|---|
| [typst/typst](https://github.com/typst/typst) | A typesetting system with a scripting language, one static binary. | Book-quality line breaking and hyphenation, `measure` for the height of any content, and page positions through `here()` and `locate()`. Introspection stops after five layout passes, so a chain of decisions that each read page positions does not converge; Press settles them outside Typst, one `typst eval` per round. Spacing inside a `context` block does not reach the content around it. Chromium print (the first PDF path) could not float figures or report page positions. |

## Rejected

| Project | What it is | Why we left it |
|---|---|---|
| [kieler/elkjs](https://github.com/kieler/elkjs) | A layered graph layout, used widely for diagrams. | Compared with pele on three state machines. With matching settings, `start` landed mid-graph, larger graphs stretched, and compound edges routed poorly. It is also asynchronous and about 1.5 MB. |
| [basementstudio/scrollytelling](https://github.com/basementstudio/scrollytelling) | Scroll-driven animation for React, built on GSAP. | Scroll position picks the frame. A Press step is a line in the fence, and print is one frame. Scroll position has no static form. |

## Explanations, steps and motion

| Project | What it is | What it covers |
|---|---|---|
| [ivarvong/lantern](https://github.com/ivarvong/lantern) | Steppable explainers rendered to SVG. | A URL per step, and running TypeScript with no build step. Both are in use. `#order/3` opens step 3. Lantern also renders a contact sheet of every step, for checking a walkthrough. That sheet is not built in Press. |
| [kitlangton/psychopomp](https://github.com/kitlangton/psychopomp) | Code-first motion graphics and narrated explainers, in Rust. | A frame as a pure function of time, and motion that keeps its velocity when interrupted. The step dot is a function of time. An interrupted step still jumps. The sound, and the way it draws pictures, are not part of a Press document. |
| [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) | A skill that explains an idea by building a working object. | How to teach an agent to write an explanation. `skills/press/SKILL.md` is the Press version. |
| [kitlangton/behold](https://github.com/kitlangton/behold) | A Markdown workspace that turns semantic fences into components. | Fence names such as `timeline`, `tree`, and `diff`. Check that vocabulary when designing a later Press type. |

## Typography and print

| Project | What it is | What it covers |
|---|---|---|
| [jemmybutton/byrne-euclid](https://github.com/jemmybutton/byrne-euclid) | Byrne's colour-coded Euclid, rebuilt in MetaPost and LaTeX. | Colour used to point at a part of a figure, and Tufte's small letters set on the figure. That is the precedent for letter markers on prose references. In HTML, a prose reference takes its node's colour. |
| [enesozturk/dimensional-drawing](https://github.com/enesozturk/dimensional-drawing) | A skill that draws UI components as dimensional drawings. | Telling parts apart by line weight, dashes, and hatching, so the picture still works when the colour is gone. A Press role has to survive grayscale print. |
| [anomalyco/justice](https://github.com/anomalyco/justice) | Knuth-Plass paragraph justification for the web. 4.5 KB, no dependencies. | Line breaking for justified prose. Press does not use it yet. |
| [chenglou/pretext](https://github.com/chenglou/pretext) | Text measurement and wrapping in TypeScript, with no DOM reflow. | Measuring a string, then wrapping it, including scripts and breaks a fixed width table misses. Press measures label glyphs into `src/text/metrics.ts` and wraps from that table. Open pretext when a label needs a script or a break the table does not cover. |
