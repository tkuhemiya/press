# Vendor icons

The icons in this folder belong to their vendors. They are not covered by Press's MIT licence.
Press draws them unchanged (scaled, never cropped, recoloured or distorted) next to the
product's node in an architecture or sequence diagram. `scripts/import-icons.ts` rebuilds
each folder from the vendor's published package; it renames files and strips metadata only.

## `aws`: AWS Architecture Icons

Source: https://aws.amazon.com/architecture/icons/ (package dated 2026-07-31, service icons at 48 px).

> We allow customers and partners to use these toolkits and assets to create architecture
> diagrams. You can also put icons in materials like whitepapers, presentations, data sheets,
> and posters.

AWS and the AWS service names are trademarks of Amazon.com, Inc. or its affiliates.

## `azure`: Azure Public Service Icons

Source: https://learn.microsoft.com/en-us/azure/architecture/icons/ (V24).

> Microsoft permits the use of these icons in architectural diagrams, training materials, or
> documentation. You can copy, distribute, and display the icons only for the permitted use
> unless granted explicit permission by Microsoft. Microsoft reserves all other rights.

Microsoft's guidelines also ask that icons are not cropped, flipped, rotated or distorted, and
not used to represent your own product. Azure is a trademark of the Microsoft group of companies.

## `gcp`: Google Cloud icons

Source: https://cloud.google.com/icons (core products and category icons).

Google publishes these icons for architecture diagrams. The icon page did not state written
terms when this set was imported; check it before relying on them beyond that use. Google Cloud
and its product names are trademarks of Google LLC.
