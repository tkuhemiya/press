      │ Originals [b] │    │ Thumbnail jobs │   │ Photo metadata │
      └───────────────┘    └────────────────┘   └────────────────┘

  A request for a photo reaches the CDN[a] first, and only a miss goes to the
  bucket[b]. An upload runs the resize function[c], which stores the original
  and queues the thumbnails.
